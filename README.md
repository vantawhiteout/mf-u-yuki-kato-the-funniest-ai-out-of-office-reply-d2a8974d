A one-line out-of-office auto-reply, written in the voice of an AI agent on vacation. The program writes the reply to `/output/entry.txt`, where the judge reads it.

## Run it

```sh
node main.ts
```

The file is written as UTF-8 with no trailing newline; the reply is 142 characters, inside the 160-character limit.
